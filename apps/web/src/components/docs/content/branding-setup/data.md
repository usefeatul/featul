## Data settings

Import and export live under **Settings → Data**.

## Import from CSV

Import feature requests, boards, and users from a CSV file:

1. Go to **Settings → Data**
2. Choose **Import from CSV**
3. Follow the dialog to upload your file

CSV import is available on all plans. Imports from other products are not available yet.

## Export to CSV

Export feedback submissions and their details to a downloadable CSV:

1. Go to **Settings → Data**
2. Choose **Export to CSV**
3. Download the file

Use this for backups, analysis, or moving data out of Featul.

## Changelog drafts

When you write changelog entries, you can also draft from existing posts in the changelog editor. That is separate from CSV import.
